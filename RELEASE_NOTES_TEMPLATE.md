## 📦 Update MCP Bundle Installation
**For Claude Desktop users:**

→ [Download artigence-linkedin-mcp-v${VERSION}.mcpb](https://github.com/ArtigenceHealthcareSystems/linkedin-mcp-server/releases/download/v${VERSION}/artigence-linkedin-mcp-v${VERSION}.mcpb)

Then click the downloaded file to install in Claude Desktop.

> **Note:** MCP Bundles do not auto-update. You need to download and install the latest `.mcpb` file for each new release.

## 🧰 Update uvx Installation
**For users with `uvx`-based MCP client configurations:**

```bash
uvx artigence-linkedin-mcp@latest
```

The `@latest` tag will always resolve to the most recent PyPI release on the next launch.
